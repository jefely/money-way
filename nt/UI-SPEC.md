## 1. 流水（Flow）✅

**列标**：`序 | 日期 | 转出账户 | 转入账户 | 金额 | 备注`　**冻结**：序

- 工具栏：添加（批量文本）/ 同步（二维码）/ 导入 / 导出
- 日期：输入 `YYMMDD`，输入 `:` 自动补当天
- 转出/转入：输入简码，失焦自动解析成真名并绑定 `id`；≥2 字符弹候选气泡
- 金额：数字键盘，保留两位小数
- 行尾 `×`：删除并重算余额
- 底部：`共 N 笔 · 合计 ¥xxx`

## 4. 路径（Money Way）

详见 [`MONEYWAY-SPEC.md`](MONEYWAY-SPEC.md)。

左右分栏：**右侧环网图**（点击高亮）、**左侧流水查询表**。

- 追踪列表列标：`序 | 日期 | 转出 | 转入 | 金额 | 备注`，与查询表同一套筛选逻辑
- 缩放/拖拽/旋转的状态与「选中追踪」状态**分开管理**
- 渲染器 `ui/mw-svg-renderer.js` 只画图；列表数据由 `graph/path-tracer.js` 输出

**左上角常驻工具条**（原「路径追踪」标题由它取代，不随左栏收展隐藏）：

```
[◀/▶]  [逆]  Money Way            [清空]（清空在左栏标题行右端）
```

- 三角：收起 / 展开左栏；收起态三角朝右（▶）
- 顺 / 逆：**一个字的按钮** —— 显示「逆」= 逆流、显示「顺」= 顺流，点一下换向（两个字的标签太占位置）
- 颜色 / 线宽 / 选线规则见下
- **点绘图区 → 左栏自动收回**（拖动 / 双指 / 长按不算点击）

**两种方向对「点左栏」和「点弧块」的规则不一样：**

- **点左栏一笔**：始终是同一条**支出倒推链**（方向只改画法与第 4 模式线宽）
- **点弧块**：只取当前方向的**一侧**，不递归 —— 逆流 = 流入它的线，顺流 = 从它流出的线

| | 逆流（默认） | 顺流 |
|---|---|---|
| 连线颜色（**全图唯一规则，无例外**） | **转入方**的统计分类 | **转出方**的统计分类 |
| 点弧块点亮 | 流入它的线 | 从它流出的线 |
| 点弧块的线色 | 转入方 = 弧块自己 → **全部同色** | 转出方 = 弧块自己 → **全部同色** |
| 第 4 模式线宽 | 看转入方类型：费用 6 → 收入·权益 1.2 | 看转出方类型：收入·权益 6 → 费用 1.2 |

这是**原理而不是某个账户的特例**：弧块的线要么全流入、要么全流出，锚点端永远是弧块本身，
所以两种方向下这一圈线都和弧块同色。费用类账户没有流出线 → 顺流点它只有页脚提示，不压暗整图。

- 其它模式的线宽两套方向相同，只有第 4 模式换表
- 换方向时焦点、缩放都不丢

链条为空时**不压暗整张图**，只在页脚说明。

## 5. 计划（Plan）= 固定收支 + 分期

> **整合原则**：分期是固定收支的**子模块**。
> 分期表是**交互界面**，固定收支是**计算聚合接口**。
> 底层统一为「计划流水」：固定收支无 `inst` 字段，分期带 `inst`。

顶部两个子视图胶囊：**固定收支** / **分期还款**。

### 5.1 子视图 A：固定收支

**列标**：`序 | 频率 | 日期 | 转出账户 | 转入账户 | 金额 | 备注`　**冻结**：序

- 频率下拉：每天 / 每月
- 日期：几号（每月）或起始日（每天）
- 行内直接编辑；**每次编辑只更新单一字段，不触发全局重绘**
- 顶部聚合：`每月收入合计 / 支出合计`（由 `getSchedulerSummary` 算）

### 5.2 子视图 B：分期还款

**列标**：`账户名称 | 分期金额 | 账单日 | 还款日 | [未来月份1] | [未来月份2] …`
**冻结**：账户名称（横向滑动时左侧不动）

- **双行一条记录**：上行为本金，下行为利息
- 新增 / 复制按钮 → 弹窗录（期数、首月、本金、利息）
- 起止月份输入（`2608`）控制矩阵范围
- 只读展示（数据来自分期规则，不在此处改金额）
- 顶部聚合：`未还本金合计 / 未还利息合计`

### 5.3 数据模型统一

```js
// 固定收支
{ id:'sched_01', isScheduled:true, freq:'monthly', day:25, from_id, to_id, amount:900 }
// 分期 = 固定 + inst
{ ...同上, amount:1060, inst:{ periods:12, firstMonth:'2026-08', principal:12000, interest:720 } }
```

引擎：`core/scheduler-engine.js`（`generateFutureFlows` / `getSchedulerSummary` / `projectMonthlyCashflow`）。

**虚实结合**：在时间轴上选某个月时，真实流水 + 该月虚拟流水混合显示，
虚拟行用虚线边框 / 半透明，让用户一眼分清「过去的钱是真钱，未来的钱是虚钱」。

## 6. 设置（Settings）

顶部六大功能：`配平 | 密码 | 配置 | 重置 | 主题 | 布局`

### 6.1 账户列表

**列标**：`简码 | 序 | 类型 | 分类 | 账户名称 | 期初 | 账单日 | 还款日 | 上移 | 删除`
**冻结**：只冻结首列「简码」+ 首行表头（像 Excel 的冻结首列 + 冻结首行）。
不冻结第二列 —— 序列跟着横滚。

- 布局是「CSS 模式」：列宽只来自 `--nt-col-accounts-*`（`shell.css` 按 `data-col` 消费），
  表宽 = 各列之和（`.nt-table { width: max-content }`）；JS 不写 `left`、
  不写 `table.style.width`、不建 `<col>`。见 [`TABLE-INTERACTION.md`](TABLE-INTERACTION.md) §三。
- 每格行内编辑：简码 / 分类 / 名称是文本框，类型是下拉，期初是金额
  （改期初 = 换掉那条 `opening` 流水），账单日 / 还款日只对负债类有意义。
- A / B 两个区域的**区号住在冻结首列里**（`td.nt-zone-tag`），长标题与极性说明
  在 `colspan=9` 的第二格 —— 横滚时区号跟着首列走，不滑走（v1.73）。
- 行尾 `↑` 与同类型的前一行交换位置；`×` 删除账户（流水一起删）。
- 末尾空行：填了「名称」就成一个新账户。

### 6.2 六个功能

| 功能 | 弹窗 | 要点 |
|---|---|---|
| **配平** | `NtModal.info` | 纯期初验证器，红绿文字展示是否平衡 |
| **密码** | `ModalPasswordForm` | 当前密码 / 新密码 / 提示词（修改密码尚未接入，按钮暂提示「后续版本」） |
| **配置** | 文本域 | 导入导出账户配置文本 |
| **重置** | `NtModal.confirmDanger` | 「重置账户（留数据）」/「重置账本（清空）」，红色 + 二次确认 |
| **主题** | 无弹窗 | 点一下切下一个，四主题循环；页脚显示当前主题 |
| **布局** | 表单 | 列宽、字号等 UI 参数 |

**工具条按钮统一**：所有页的 `.nt-vbar .nt-btn` 都是高 26 / 左右内边距 8 /
字号 `--nt-vbar-font`（默认 12）。设置页 7 个元素（标题 + 6 按钮）禁止折行，
390px 下排成一行；字号被调大时横向滑动，不换行。

**密码提示词（门禁）**：首次设置密码时多一个可选输入框「提示词」，
内容存 `localStorage['nt_pw_hint']`（必须在解锁前可读，所以不加密）。
解锁时显示在密码框**正下方一行**、左对齐、12px muted —— 不写「提示词：」前缀，
没填就整行不出现（`hidden`）。

## 7. 校验（Validation）

Tab：`账本说明 | 账本校验 | 账本配置 | 赞助感谢`

三张卡片（消费 `validator.js` 的 `{ ok, issues[] }`）：

| 卡片 | 判据 | 展示 |
|---|---|---|
| ① 发生额平衡 | 左方合计 = 右方合计 | 差额 0 → 绿色「平衡」；否则红色差额 |
| ② 会计恒等式 | 资产 + 费用 = 负债 + 权益 + 收入 | 同上 |
| ③ 数据完整性 | 断链笔数、单边笔数 | 列出前 N 条并定位 |

底部小字：`对不上的名称 0 个 · 单边 0 笔`
