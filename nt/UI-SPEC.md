## 1. 流水（Flow）✅

**列标**：`序 | 日期 | 转出节点 | 转入节点 | 金额 | 备注`　**冻结**：序

- 工具栏：添加（批量文本）/ 同步（二维码）/ 导入 / 导出
- **同步弹窗（v1.90）**：自适应天数 ——
  右侧竖轮选截止日（年份在竖轮上方、右缘与竖轮对齐）；从这天往前**按天**装流水，
  一张码装满为止（`core/sync-window.js` 二分找最大窗口；装不下的那天整天不要）；
  二维码固定 220×220 靠左，下方写明「包含 9/5 — 9/9 · N 笔」，紧跟「保存二维码图片」；
  点二维码用第二个 `<dialog>` 全屏放大；没有流水时同尺寸虚线占位，有码无码布局都不动；
  ② 一个文本框打通复制与接收：复制 / 清空 / 粘贴 / 同步（同步＝合并框里的内容）
- 日期：输入 `YYMMDD`，输入 `:` 自动补当天
- 转出/转入：输入简码，失焦自动解析成真名并绑定 `id`；≥2 字符弹候选气泡
- 金额：数字键盘，保留两位小数
- 行尾 `×`：删除并重算余额
- 底部：`共 N 笔 · 合计 ¥xxx`

## 2. 统计（Stats）

两个子视图，顶部胶囊切换：**分类** / **汇总**。
筛选栏：`分类/汇总`、`清空`、`区间 / 年份 / 月份`。

- 选「月份」时 1–12 排成**一行**（`#nt-stats-pills[data-scope="month"]` 走 12 列栅格，
  390px 下每格约 28px、桌面容器上限 640px）；年份（个数不定）和区间（两个日期框）
  仍用默认 6 列，不吃这套规则。

### 2.1 分类视图

三块**等宽并排**（和查询页的 A/B/C 三联同一套排布：`repeat(3, minmax(0,1fr))`、
栏间一条分隔线、≤900px 一屏一块横向吸附），只统计**选中区间（本期）**，
不再混入全账本「当前余额」：

- **存量**（资产 / 负债 / 权益）：`分类 | 节点 | 期初 | 本期增加 | 本期减少 | 期末`
  - 期初 = 区间开始前余额；期末 = 期初 + 增加 − 减少；
  - 负债和应付同口径：转出=欠款增加、转入=欠款减少；正数=欠款，负余额=多还（显示「多还 ¥…」）。
- **流量**（收入 / 费用 / 成本）：`分类 | 节点 | 本期收入/支出 | 本期退回 | 净额`
  - 收入：转出=收入、转入=退回；费用/成本：转入=支出、转出=退回；
  - 净额已扣退回，不显示余额。
- 全零分类默认隐藏；分类按期末/净额绝对值降序。
- **列宽可调且会记住**：三块表各自一套 `--nt-col-<表>-*` 参数（默认是百分比铺满），
  拖动后整表切成固定 px 并写进账本参数，重开/重画都按新宽度还原。

> 三块表在 901–1179 这种中等宽度下也保持三栏并排（以前查询块会被折到第二行，
> 和查询页放一起看就是「两边不是一回事」）。

### 2.2 分类查询

第三块，接在「存量 / 流量」右侧（手机第三屏）：

- 输入框：填**账户分类**关键字，如 `储蓄`；空输入不列流水；
- 时间段：跟当前统计范围一致（月份 / 年份 / 区间 / 全部）；
- 命中：一笔流水只要**转出方或转入方任一账户的分类**包含关键字，就列出；
- 列：`日期 | 转出 | 转入 | 金额 | 备注`，日期倒序；
- 底部状态栏显示「分类查询「储蓄」N 笔」。

### 2.3 汇总视图

**列标**：`序 | 节点名称 | 当前结余 | 转出 | 转入 | 转出历史 | 转入历史 | 期初 | 类型 | 分类 | 账单日 | 还款日`
**冻结**：序、节点名称

- 大类合计行：深色背景高亮（如「资产类合计」）
- 所有金额只读，由 `balance-calculator.js` 实时算

## 3. 查询（Query）

**列标**：`序 | 日期 | 转出节点 | 转入节点 | 金额 | 备注`（6 列，不冻结）

- 条件：日期起止 / 转出 / 转入 / 金额 / 备注（多条件联合）
- **转出、转入回车（或失焦）才筛选**，输入过程中不重画：
  打简码时每按一个键就筛一次又闪又慢，而且替换时机取决于打到第几个字符。
- **转出、转入填同一个节点** = 该节点的「转出 + 转入」一起列（不是「与」）：
  - 一笔流水不可能自己转给自己，两栏同值时按「与」筛永远是 0 行；
  - 写法不同但指向同一账户（一个打名字、一个打简码）也算同一个节点；
  - 时间段留空 = 该节点的全部流水；填了 `261101~261130` 这种就只留区间内。
- **简码在回车后变成节点名字**：在转出 / 转入框里打完 `ZHC` 再回车，框里变成「招行储」。
  只在名字全等或简码全等时替换 —— 打「招」不会被补成「招行储」，否则没法再做模糊搜索。
- 结果按**日期升序**（同一天保持录入顺序），因为同一个节点的转出/转入合在一起看时，
  录入顺序是乱的。
- 底部联动统计：`A: 37 笔 ¥74.00 · B: …`
- 备注被省略号截断时，点击弹层看全文
- 三段独立查询表，表单状态与渲染分离；查询逻辑在 `core/query-engine.js`

## 4. 路径（Money Way）

详见 [`MONEYWAY-SPEC.md`](MONEYWAY-SPEC.md)。

左右分栏：**右侧环网图**（点击高亮）、**左侧流水查询表**。

- 追踪列表列标：`序 | 日期 | 转出 | 转入 | 金额 | 备注`，与查询表同一套筛选逻辑：
  - 日期 / 金额 / 备注：边打边筛；
  - 转出 / 转入：**回车或失焦才筛**；简码在回车后变成节点名字；
  - 转出、转入填同一个节点 = 该节点的转出 + 转入一起列（同查询页）
- 缩放/拖拽/旋转的状态与「选中追踪」状态**分开管理**
- 渲染器 `ui/mw-svg-renderer.js` 只画图；列表数据由 `graph/path-tracer.js` 输出

**左上角常驻工具条**（原「路径追踪」标题由它取代，不随左栏收展隐藏）：

```
[◀/▶]  Money Way            [清空]（清空在左栏标题行右端）
```

- 三角：收起 / 展开左栏；收起态三角朝右（▶）
- **没有顺/逆开关** —— 2026-11 已删除，点弧块看哪一侧改由**节点类型**决定
- **点绘图区 → 左栏自动收回**（拖动 / 双指 / 长按不算点击）

**点左栏和点弧块是两条不同的路：**

- **点左栏一笔**：**逐层推进、逐笔累加**的资金路径 ——
  向后按「转入」追上级、向前按「转出」追下级，累计到选中金额为止（见 `MONEYWAY-SPEC.md` §5.2）
- **点弧块**：只取**一侧**，不递归 —— 看哪一侧由**节点类型**决定

| 节点类型 | 看哪一侧 |
|---|---|
| 收入类 / 权益类 | **流出**（钱从它出发去了哪） |
| 费用类 | **流入**（钱从哪来到它） |
| 资产类 / 负债类 / 成本类 | **两侧都看**（中转站，进出都是它的故事） |

**连线颜色全图唯一规则**：**永远是转出节点的颜色**，与转入方、与统计分类都无关。
所以点某个账户时，同色线 = 流出，异色线 = 流入。

链条为空时**不压暗整张图**，只在页脚说明。

## 5. 计划（Plan）= 固定收支 + 分期

> **整合原则**：分期是固定收支的**子模块**。
> 分期表是**交互界面**，固定收支是**计算聚合接口**。
> 底层统一为「计划流水」：固定收支无 `inst` 字段，分期带 `inst`。

顶部两个子视图胶囊：**固定收支** / **分期还款**。

### 5.1 子视图 A：固定收支

**列标**：`序 | 频率 | 日期 | 转出节点 | 转入节点 | 金额 | 备注`　**冻结**：序

- 频率下拉：每天 / 每月
- 日期：几号（每月）或起始日（每天）
- **每月到期自动落成真实流水**；每日不自动，流水页只显示**当天一条**虚拟行，点 ▲ 才生效
- 自动落账的备注取固定表模板备注；模板为空就为空（非分期不补「第几期」）
- 固定表选「每天」时，日期格显示横线且不可录入；切回「每月」恢复几号输入
- 自动落的那笔可像普通流水一样修改 / 删除；删掉后这一期不再自动补
- 末尾固定 **10 个空行**：不显示默认「每月」，日期/金额格也不放占位文字，整行留白
- 转出 / 转入格可以写账本里没有的新节点名；保存时自动补成空类型的「未分类」节点
- 一行填完、**离开这一行**才建规则（金额填完点同行备注不算离开，备注不会被抢建）
- 行内直接编辑；**每次编辑只更新单一字段，不触发全局重绘**
- 顶部聚合：`每月收入合计 / 支出合计`（由 `getSchedulerSummary` 算）

### 5.2 子视图 B：分期还款

**列标**：`节点名称 | 分期金额 | 账单日 | 还款日 | [未来月份1] | [未来月份2] …`
**冻结**：节点名称（横向滑动时左侧不动）

- **双行一条记录**：上行为本金，下行为利息
- 新增 / 复制按钮 → 弹窗录（期数、首月、本金、利息）
- 起止月份输入（`2608`）控制矩阵范围
- 只读展示（数据来自分期规则，不在此处改金额）
- 顶部聚合：`未还本金合计 / 未还利息合计`

### 5.3 数据模型统一

```js
// 固定收支
{ id:'sched_01', isScheduled:true, freq:'monthly', day:25, from_id, to_id, amount:900 }
// 分期 = 固定 + inst
{ ...同上, amount:1060, inst:{ periods:12, firstMonth:'2026-08', principal:12000, interest:720 } }
```

引擎：`core/scheduler-engine.js`（`generateFutureFlows` / `getSchedulerSummary` / `projectMonthlyCashflow`）。

**虚实结合**：在时间轴上选某个月时，真实流水 + 该月虚拟流水混合显示，
虚拟行用虚线边框 / 半透明，让用户一眼分清「过去的钱是真钱，未来的钱是虚钱」。

## 6. 设置（Settings）

顶部六大功能：`配平 | 密码 | 配置 | 重置 | 主题 | 布局`

### 6.1 账户列表

**列标**：`简码 | 序 | 类型 | 分类 | 节点名称 | 期初 | 账单日 | 还款日 | 上移 | 删除`
**冻结**：只冻结首列「简码」+ 首行表头（像 Excel 的冻结首列 + 冻结首行）。
不冻结第二列 —— 序列跟着横滚。

- 布局是「CSS 模式」：列宽只来自 `--nt-col-accounts-*`（`shell.css` 按 `data-col` 消费），
  表宽 = 各列之和（`.nt-table { width: max-content }`）；JS 不写 `left`、
  不写 `table.style.width`、不建 `<col>`。见 [`TABLE-INTERACTION.md`](TABLE-INTERACTION.md) §三。
- 每格行内编辑：简码 / 分类 / 名称是文本框，类型是下拉，期初是金额
  （改期初 = 换掉那条 `opening` 流水），账单日 / 还款日只对负债类有意义。
- **期初方向**：资产 / 费用 / 成本 = `期初余额 → 账户`；负债 / 权益 / 收入 = `账户 → 期初余额`。
  负债欠款填正数，即「负债账户 → 期初余额」；旧存档里方向录反的 `opening` 流水在迁移时自动摆正。
- A / B 两个区域的**区号住在冻结首列里**（`td.nt-zone-tag`），长标题与极性说明
  在 `colspan=9` 的第二格 —— 横滚时区号跟着首列走，不滑走（v1.73）。
- 行尾 `↑` 与同类型的前一行交换位置；`×` 删除账户（流水一起删）。
- 末尾固定 **10 个空行**（在 U 区之后、备注区之前）；建行时按填写的类型自动归 A / B / U。
- 空行填了「名称」就成一个新账户；类型留空按资产类。

### 6.1.1 备注区（v1.92）

A / B 两个区域**下面**再来一个区域，区域名就叫「备注」，说明文字「成员归属/项目说明」：

**列**：`备注 | 类型 | 内容（colspan=6，右边到还款日列）| 删除（colspan=2）`

- 第一列是**备注简码**，和账户简码是两套命名空间（独立于 A/B）；冻结列照旧
- 第二列是**类型**：`成员 / 商家 / 项目 / 用途`，只做分类，不参与任何校验
- 内容格从类型列之后一直吃到「还款日」列的右边框，左对齐；没有选项框
- 行尾只有一个删除按钮；末尾空行填了内容就成一条
- 整个备注体系只做统计归类，以及**在流水备注框里输入简码自动代入文本**
  （失焦时 `noteTextByCode()` 命中就替换，例：备注框输入 `M1` → 「张三」）
- 存储：`state.notes = [{ id, code, type, text }]`；实现 `ui/note-table.js`

### 6.2 六个功能

| 功能 | 弹窗 | 要点 |
|---|---|---|
| **配平** | `NtModal.info` | 纯期初验证器，红绿文字展示是否平衡 |
| **密码** | `ModalPasswordForm` | 当前密码 / 新密码 / 提示词（修改密码尚未接入，按钮暂提示「后续版本」） |
| **配置** | 文本域 | 导入导出账户配置文本 |
| **重置** | `NtModal.confirmDanger` | 「重置账户（留数据）」/「重置账本（清空）」，红色 + 二次确认 |
| **主题** | 无弹窗 | 点一下切下一个，四主题循环；页脚显示当前主题 |
| **布局** | 表单 | 列宽、字号等 UI 参数 |

**工具条按钮统一**：所有页的工具条（`.nt-vbar`）与查询面板头（`.nt-query-head`）
共用同一套参数 —— 高度 `--nt-vbar-h`、按钮高 `--nt-btn-h`（默认 26）、
间距 `--nt-btn-gap`、样式 `data-btn-style`。在布局面板「主界面 › 按钮尺寸 / 按钮区」
改一次，所有页同时生效。设置页 7 个元素（标题 + 6 按钮）禁止折行，390px 下排成一行；
字号被调大时横向滑动，不换行。

**密码提示词（门禁）**：首次设置密码时多一个可选输入框「提示词」，
内容存 `localStorage['nt_pw_hint']`（必须在解锁前可读，所以不加密）。
解锁时显示在密码框**正下方一行**、左对齐、12px muted —— 不写「提示词：」前缀，
没填就整行不出现（`hidden`）。

Tab：`账本说明 | 账本校验 | 赞助感谢`

三张卡片（消费 `validator.js` 的 `{ ok, issues[] }`）：

### 7.1 赞助感谢 · 感谢墙（v1.82 起：远程加密名单）

站长维护一份**加密名单**放在仓库里，用户打开软件时自动拉取、解密、显示：

```
明文（站长手里）                     仓库（公开）
_tools/thanks.plain.json  --加密-->  nt/thanks.enc.json
  { qr, donors:[…] }                   { v, salt, iv, ct }（base64）
```

**管理界面**（v1.84 加）：`nt/thanks-admin.html`

- 本地 `http://127.0.0.1:8080/nt/thanks-admin.html`
- 线上 `https://jefely.github.io/money-way/nt/thanks-admin.html`
- 功能：编辑名单（一行一个）、添加 PNG 图片（多选，缩略图可删）、选收款码、
  「从仓库载入当前名单」（用内置密钥解密回填）、生成加密 JSON、复制 / 下载
  `thanks.enc.json`。生成后替换仓库里的同名文件即可，用户端下次打开自动生效。

也可以用命令行：`node _tools/thanks_encrypt.mjs`（读 `_tools/thanks.plain.json`）。

- **加密**：`PBKDF2-SHA256(100000) → AES-GCM-256`，密钥内置在 `ui/thanks-wall.js`
  的 `secret()`（拆段拼接）—— 只防「随手看明文 / 随手改」，不是密码学秘密
- **更新**：改 `_tools/thanks.plain.json` → `node _tools/thanks_encrypt.mjs` → 提交
  `nt/thanks.enc.json`；用户端下次打开自动换新（fetch 带 `?t=` 绕开 SW 缓存）
- **离线**：解密结果缓存 `localStorage['nt_thanks_cache_v1']`；拉不到 / 解不开时用缓存，
  首次打开就离线则显示空墙
- **渲染**：名字方块（直角，按字数分档 46 / 66 / 92，配色按名字哈希取调色板）
  + PNG 图片（92×92，`object-fit: cover`）；只读，没有本机增删入口
- **PNG 支持**：名单里 `{ "img": "路径或 dataURL" }`；加密脚本会把本地 PNG 读成
  dataURL，加密文件自包含，用户端不需要再取图（也就能离线）
- **收款码**：名单里的 `qr`（PNG 路径 / dataURL），没有就不显示
- 实现：`ui/thanks-wall.js` + `css/thanks.css`；加密工具 `_tools/thanks_encrypt.mjs`
