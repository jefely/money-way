# 界面参数表（路径页 / 环图）

> 这份表是**当前线上那版的定稿参数**。改任何一项都要同时改这里，
> 否则下次调参没有基准。版本见 `js/core/version.js` 的 `APP_VER`。

## 环图几何（`ui/mw-svg-renderer.js`）

| 参数 | 值 | 说明 |
|---|---|---|
| `BASE_SIZE` | 1800 | 单文件版的基准画布 |
| `size` | **6000** | 实际 viewBox（= 基准 × 3.33），放大到任意尺寸都是矢量清晰 |
| `RATIO` | 6000 / 1800 = **3.333** | 所有像素量按它等比放大 |
| `rOut` | 640 × RATIO = **2133** | 环外半径 |
| `thick` | 44 × RATIO = **147** | 环厚 |
| `rIn` | `rOut - thick` = **1986** | 环内半径 |

## 环内遮罩

| 参数 | 值 |
|---|---|
| 填充 | `.mw-mask { fill: var(--nt-bg) }` |
| 不透明度 | **0.48** |
| 绘制位置 | 在**连线之前**（先铺底色圆打底，线在它上面） |

## 弧块与标签

| 参数 | 值 |
|---|---|
| 描边 | `#6b7280`，`0.9 × RATIO`，`55%` |
| 分类顺序 | 权益 → 负债 → 费用 → 资产 → 收入 → 其它（9 点起顺时针） |
| 颜色 | 24 色 maximin 调色板（任意两色 ΔE76 ≥ 30；前 11 个各占一个色系；第 25 个起黄金角 + 暗带） |
| 标签字号 | `13×RATIO ~ 28×RATIO`，按弧长与环厚取小 |
| 标签半径 | 放得下：`rOut + 8×RATIO`；放不下：`rOut + 46×RATIO + 10×RATIO`（锥底 +10） |
| 尖锥引线 | 弧长 < 文字宽 × 1.5 时画；锥尖在 `rOut`，锥底在 `rOut + 46×RATIO`，半宽 `5×RATIO`，同色 50% |

## 线宽与透明度（`ui/path-view.js` + `graph/mw-path-calculator.js`）

| 参数 | 值 | 说明 |
|---|---|---|
| `W_MID` | **2.4** | 默认线宽（单文件版同值），× RATIO |
| `DEPTH_WIDTHS` | `[6, 4.8, 3.6, 2.4, 1.2]` | 按「离费用端几跳」分档，点弧块（acc 模式）用；**两个方向相同** |
| 追踪线宽·逆流 | **费用 6 / 资产 3.6 / 负债 2.4 / 收入·权益 1.2** | 看线的**转入方**类型，× RATIO；非命中线 1.2 |
| 追踪线宽·顺流 | **收入·权益 6 / 负债 4 / 资产(储蓄) 2.4 / 费用 1.2** | 看线的**转出方**类型，× RATIO；非命中线 1.2 |
| 连线颜色 | 逆流取**转入方**统计分类 / 顺流取**转出方**统计分类 | **全图唯一规则、无例外**；点弧块时一圈线同色（那一端就是弧块本身） |
| `PICK_BOOST` | **1.35** | 命中线在档位上再加权 |
| 命中线额外系数 | **×0.35** | 用户定的，别再放大 |
| 其它线（有命中时） | `W_MID × 0.45` | `PICK_SHRINK` |
| `OPACITY.GLOBAL` | **0.52** | 无聚焦 |
| `OPACITY.HIT` | **0.95** | 命中 |
| `OPACITY.DIM` | **0.25** | 有聚焦时其它线 |
| 空链 | **不压暗** | 没有命中时按全局透明度画，页脚说明（「没有上游流水」/「没有流入它的线」/「没有从它流出的线」） |

## 手势（`ui/chart-gestures.js`）

| 参数 | 值 | 说明 |
|---|---|---|
| `PAN_GAIN` | **1.2** | 屏幕 px → viewBox 单位的额外倍数；1.0 是 1:1 跟手 |
| 右键旋转灵敏度 | **0.08 度/px** | 按住右键横向拖动 |
| 双指旋转 | 两指连线角度差 | 转多少度图转多少度，跨 ±180 归一化 |
| 缩放范围 | 0.3 ~ 6 | 滚轮 / 双指捏合，步长 0.1 |
| 双击复位 | 空白处生效 | 点在弧块上不复位（防误触） |
| 拖动期间 | `<g>` 临时挂 `will-change: transform` | 走合成层跟手；松手撤掉并踢一次重绘回矢量 |
| 拖动期间降质 | 隐藏 `text`、`shape-rendering: optimizeSpeed` | 松手恢复 |

## 路径页布局

| 参数 | 值 |
|---|---|
| 图容器 | `position: fixed`、视口居中、`min(94vw, 86vh)`、`z-index: 1` |
| 侧栏 | `z-index: 2`、背景 `color-mix(--nt-bg-soft 15%, transparent)`（几乎全透） |
| 侧栏宽度 | `--nt-pw-side-w`，默认 320，上限 `min(窗口宽×0.92, …)`；收起 = `0` |
| 窄屏侧栏上限 | `92vw`（宽于 820px 时不生效） |
| 左上工具条 `.pw-tools` | `position: fixed`、`left: 10px`、`top: 50px`、`z-index: 7`、间距 8px；**不随侧栏收展隐藏** |
| 工具条内容 | 三角（22×22，收起态 ▶ / 展开态 ◀）+ 顺逆切换 + `Money Way`（13px/800） |
| 顺逆切换 `.pw-dir` | 单个按钮：`逆流 ⇄ 顺流`，高 22、`padding 0 7px`；当前方向 `--nt-primary` + 700，另一个 `--nt-text-light` |
| 左栏标题行 | 只剩「清空」（右对齐）；原「路径追踪」标题已由工具条取代 |
| 点绘图区 | **自动收起左栏**：pointerdown→up 位移 ≤8px、时长 <700ms、单指、左键；拖动 / 双指 / 长按不算 |
| 筛选框位移 | `transform: translateX(-5px)`（整排左移） |
| 环图统计范围 | **由左栏筛选框决定**，不是全账本 |

## 路径页数据规则

| 参数 | 值 |
|---|---|
| 期初流水 | 不进图、不进左栏（`t.opening` 一律过滤） |
| 折叠 / 阈值 | **没有**（单文件版是「有多少笔画多少笔」） |
| 单位角 | `(360 − 分类数×0.8) ÷ (笔数×2)`，下限 60 |
| 日期筛选 | `260801` / `2608` / `26` / `260801-260807`（`- ~ ～ — 到` 都认） |
| 账户筛选 | 全名片段或**简码**（不区分大小写） |
| 追踪方向 | `逆流` / `顺流` 的两套规则：点左栏只改画法（链不变）；点弧块改**看哪一侧的线** |
| 链路·侧栏条目 | 这笔的**收款账户**往上游追（含这笔自己）；单边流水只剩它自己；方向不选链 |
| 链路·点弧块 | **只取直接相连的线**（不递归）：逆流 = 流入它的，顺流 = 从它流出的 |
| 点弧块的颜色 | 按上面的唯一规则 → 一圈线同色（颜色认账户，方向决定看「进」还是「出」） |
| 环路 | 上游链用 visited 切断，倒卡不会死循环 |

## 沿用但容易改错的点

- `COL_KEYS` 是**只追加**的（用户列宽按位置存成数组，插入会整体错位）
- 拖动列宽存到 `user` 槽，面板改默认值存 `defaults`，导出读合并值
- 改完必须跑 `node nt/tools/check-rules.mjs`（含 ESM 语法检查）与 `node --test nt/tests/*.test.mjs`
