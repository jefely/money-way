# 界面参数表（路径页 / 环图）

> **这份表现在是「可调参数」的说明书**，不再只是定稿记录。
> 30 个环图参数已经进「界面参数」面板：**设置 → 布局**（或 `?debug=1`）→ 顶部**「路径」**屏
> → 「环图·几何 / 标签 / 线 / 规则」四组。改一项图会立刻重排，随账本加密存盘。
>
> 代码里的唯一源是 [`js/core/mw-settings.js`](js/core/mw-settings.js)（SCHEMA + 默认值 + 上下限）。
> 本文档与它不一致时，以代码为准，但要回来把这份表改对 —— 否则下次调参没有基准。
> 版本见 `js/core/version.js` 的 `APP_VER`。

## 怎么调

| 入口 | 说明 |
|---|---|
| 设置 tab → `布局` | 打开界面参数面板（和表格参数同一个面板） |
| `?debug=1` | 启动时直接挂出面板 |
| 面板顶部「路径」屏 | 环图四组参数都在这里；「主界面」是表格与外壳那 43 项 |
| `存默认` / `存用户` | 两层存储，`存用户` 优先；导出默认设置会带上环图参数 |
| 面板底部「恢复默认」 | 环图一起回到本表的默认值 |

**单位是「基准单位」**：面板上写 640，实际画出来是 640 × 3.33 ≈ 2133。
这样面板里的数字就是单文件版的像素量，改 1 就是改 1，不需要心算比例。

## 环图·几何

| 参数 | 默认 | 说明 |
|---|---|---|
| 环半径 | 640 | 环外半径（基准单位）。上限 760：再大标签会被画布边缘切掉 |
| 环厚 | 44 | `rIn = rOut − 环厚`。超过环半径时内径兜底为 1，不会出现负半径 |
| 扇区分界线宽 | 0.6 | 统计分类之间的分隔线 |
| 扇区分界线不透明度 | 0.28 | |
| 弧块描边宽 | 2.4 | 弧块之间的分界（同色弧块挨着时全靠它） |
| 弧块描边不透明度 | 0.75 | 描边颜色按主题：浅色纯白 / 深色纯黑 |

**画布固定 6000**（`MW_SIZE`），不进面板 —— 改它只是整体缩放，不是风格。

## 环图·标签

| 参数 | 默认 | 说明 |
|---|---|---|
| 字号下限 | 12 | 侧栏展开时图区只有 400 多 px，再小就看不清 |
| 字号上限 | 27 | 大弧块最多这么大 |
| 拥挤判定倍数 | 1.5 | `弧长 < 文字宽 × 该值` → 判为放不下，走锥形引线 |
| 拥挤字号下限 | 18 | 走锥形的标签被推到环外，周围没别的元件，可以给得更足 |
| 标签外移 | 8 | 放得下时，文字在 `rOut + 该值` |
| 锥形第一档 | 46 | 锥底半径 = `rOut + 该值` |
| 锥形第二档 | 115 | **连续**两个需要锥形时，第二个用这一档，把标签错开成两层 |
| 锥形半宽 | 5 | 锥底半宽（像素换算成角度 = 该值 / 锥底半径） |
| 锥形不透明度 | 0.5 | 引线用弧块自己的颜色 |
| 锥底文字偏移 | 10 | 文字再往外让这么多，避免压着锥底 |

字号的实际取值：`max(下限, min(上限, 弧长/字数 × 1.05, 环厚 × 0.58))`；
走锥形时再抬到 `max(拥挤字号下限, 上面那个)`。
**没有「太窄就不画标签」** —— 单文件版每个弧块都有标签，窄块靠锥形错开。

标签内容 = 账户名 + 该账户在当前筛选范围内参与的金额合计（转出+转入）。

## 环图·线

| 参数 | 默认 | 说明 |
|---|---|---|
| 默认线宽 | 2.4 | 单文件版的 `W_MID` |
| 全局透明度 | 0.52 | 没有焦点时 |
| 命中透明度 | 0.95 | 命中线 |
| 压暗透明度 | 0.25 | 有焦点时其它线 |
| 命中带宽度 | 14 | 线的透明命中区（线只有 2px，直接点不中），最小 2 |
| 遮罩不透明度 | 0.55 | **只在单线模式**画；基本模式 0（不要黑遮罩） |
| 圆心把手比例 | 0.25 | 透明拖动把手直径 = 环直径 × 该值 |

## 环图·规则

| 参数 | 默认 | 说明 |
|---|---|---|
| 分类间隙角 | 0.8 | 统计分类之间固定留的缝（度）。改 0 时四个单位正好铺满 360° |
| 追踪深度 | 12 | 侧栏追踪沿上游最多追几跳（环路用 visited 切断，不靠这个值） |
| 追踪非命中线宽 | 1.2 | 追踪模式里不在链上的线压到这一档 |
| 命中加权 | 1.35 | 色块模式命中线在层级档位上的加权 |
| 命中收缩 | 0.45 | 色块模式非命中线的收缩系数 |
| 命中额外系数 | 0.35 | 用户定的「选中线还是偏粗」，别再放大 |
| 基本模式线宽倍数 | 0.75 | 基本模式比 `默认线宽` 细一级 |

单位角公式：`(360 − 分类数 × 分类间隙角) ÷ (笔数 × 2)`，总量下限 60°。
单位弧长 = 单位角（弧度）× 环半径，是线宽的基准。

## 线宽规则（四种模式，互不干扰）

| 模式 | 怎么点出来的 | 线宽 |
|---|---|---|
| 基本 `null` | 默认 | `默认线宽 × 基本模式线宽倍数` |
| 色块 `acc` | 点弧块 | 命中线 = 层级档位 `[6, 4.8, 3.6, 2.4, 1.2]` × 命中加权 × 命中额外系数；其它线 = `默认线宽 × 命中收缩` |
| 单线 `tx` | 点一条线 | 命中 = `默认线宽 × 1.0`（粗一级），其它同级但被遮罩盖住 |
| 追踪 `trace` | 点侧栏条目 | 命中 = 按下表取档；其它线 = `追踪非命中线宽` |

追踪档位看**当前方向那一端**的账户类型（见下）。

| 方向 | 看哪端 | 费用 | 资产 | 负债 | 收入 / 权益 |
|---|---|---|---|---|---|
| 逆流 `up` | 转入方 | 6 | 3.6 | 2.4 | 1.2 |
| 顺流 `down` | 转出方 | 1.2 | 2.4 | 4 | 6 |

连线颜色：**全图唯一规则、无例外** —— 逆流取**转入方**的统计分类，顺流取**转出方**的统计分类。
点弧块时，那一端就是弧块本身，所以一圈线同色。

## 未参数化（改了要动代码）

| 项 | 位置 | 为什么不做成参数 |
|---|---|---|
| 画布边长 6000 | `mw-settings.js` 的 `MW_SIZE` | 只是整体分辨率，改了等于缩放 |

| 层级档位 `[6, 4.8, 3.6, 2.4, 1.2]` | `graph/mw-path-calculator.js` 的 `DEPTH_WIDTHS` | 5 个数的数组，面板没有合适的输入控件 |
| 24 色调色板 | `graph/mw-path-calculator.js` 的 `CATEGORY_PALETTE` | 离线算好的 maximin 配色，任意两色 ΔE76 ≥ 24 |

## 手势（`ui/chart-gestures.js`）

| 参数 | 值 | 说明 |
|---|---|---|
| `PAN_GAIN` | 1.2 | 屏幕 px → viewBox 单位的额外倍数；1.0 是 1:1 跟手 |
| 右键旋转 | 按「绕圆心转过的角度」 | 按住右键横向/竖向拖动都跟手 |
| 双指旋转 | 两指连线角度差 | 跨 ±180 归一化 |
| 缩放范围 | 0.3 ~ 6 | 滚轮 / 双指捏合，步长 0.1 |
| 双击复位 | 空白处生效 | 点在弧块上不复位（防误触） |
| 拖动期间降质 | 挂 `will-change: transform` | 走合成层跟手；松手撤掉并踢一次重绘回矢量 |

## 路径页数据规则

| 参数 | 值 |
|---|---|
| 期初流水 | 不进图、不进左栏（`t.opening` 一律过滤） |
| 折叠 / 阈值 | **没有**（单文件版是「有多少笔画多少笔」） |
| 日期筛选 | `260801` / `2608` / `26` / `260801-260807`（`- ~ ～ — 到` 都认） |
| 账户筛选 | 全名片段或**简码**（不区分大小写） |
| 追踪方向 | 逆流/顺流两套规则：点左栏只改画法（链不变）；点弧块改**看哪一侧的线** |
| 链路·侧栏条目 | 这笔的**收款账户**往上游追（含这笔自己）；深度受「追踪深度」限制 |
| 链路·点弧块 | 只取当前方向的一侧（不递归）：逆流 = 流入它的线，顺流 = 从它流出的线 |
| 点弧块的颜色 | 锚点端就是弧块本身 → 两种方向都是**它自己的分类色** |
| 空链 | **不压暗**：没有命中时按全局透明度画，页脚写「没有流入它的线 / 没有从它流出的线」 |
| 环路 | 上游链用 visited 切断，倒卡不会死循环 |

## 沿用但容易改错的点

- `COL_KEYS` 是**只追加**的（用户列宽按位置存成数组，插入会整体错位）
- 拖动列宽存到 `user` 槽，面板改默认值存 `defaults`，导出读合并值
- **渲染器里禁止三角函数**（门禁会查）：坐标只能由 `graph/` 算好，`mw-svg-renderer.js` 只拼字符串
- 新增 `js/` 文件三件事：文件头写 `// 界面：…`、跑 `node nt/tools/js-map.mjs --write`、把路径加进 `sw.js` 的 `ASSETS`
- 改完必须跑 `node nt/tools/check-rules.mjs`（含 ESM 语法检查）与 `node --test nt/tests/*.test.mjs`
