1. 生成后点「下载 thanks.enc.json」；
2. 用它替换仓库里的 nt/thanks.enc.json（GitHub 网页上传或 git 提交都行）；
3. 提交后，用户打开「校验 → 赞助感谢」会自动拉取并解密；离线时用上一次的缓存。

关于加密：密钥内置在 nt/js/ui/thanks-wall.js 里，这是纯静态站点， 所以本质是混淆——挡得住随手查看，挡不住铁了心的人。
