# LifeVein · 时间流里的泡（口径）

> 名字：**LifeVein**（一个词，L / V 大写）、**页面名**；tab 上写两字「**脉络**」。
> 旧名 `Money Vein` 已取消（2026-11-08）。
> 状态：**已接进产品** `nt-v1.489`，Canvas 渲染，真账本 25 个存量节点 / 402 笔流水跑通。

---

## 一、它是什么

**一张静态的时间图 + 一个视口。** 不是列表，不是逐帧动画：

- **停域**（屏幕偏上的一条绿线）＝「**现在**」。
- **泡＝一个节点在这一刻的存量**。有存量才有泡；归零收缩成质点，**不删除**。
- **资产 / 负债**是存量节点：每个账户只有一个泡，驻留在停域带上，半径跟着「现在」的余额变。
- **收入 / 费用 / 成本**不持有存量：每一笔流水一个泡，钉在时间点上。
- **所有泡一直存在**；滚动只裁视口，反向拖能退回去（时间倒流）。

## 二、六条泳道（三域是粗分）

从左到右＝钱的动线，**越常动的越靠近中转站**：

| 泳道 | 宽度 | 为什么在这 |
|---|---|---|
| 权益 | 10% | 老本，一年动不了几次 |
| 收入 | 18% | 钱从外面进来 |
| 负债 | 16% | 紧贴资产：借钱进卡、还款出卡，线只跨一步 |
| **资产** | 26% | 中转站，所有钱的必经之地 |
| 费用 | 20% | 日常消费最高频，线最短 |
| 成本 | 10% | 买大件低频，还要折旧转成费用 |

**同一根轴上的多个账户从上往下排**（3 张信用卡就排 3 行），围绕停域线上下铺开。
空类型（U 区）不进任何泳道，不画。

## 三、视觉规则（2026-11-11 起：气泡，不再连线）

取舍写在 [BUBBLE-FEASIBILITY.md](BUBBLE-FEASIBILITY.md)。摘要：

| 规则 | 实现 |
|---|---|
| 时间 | 过去在上，现在在正中，未来在下。四条等高带，中间两条是事件视界 |
| 进度 | 日期线过 75% 高度开始，过 25% 结束。只跟滚动走，上拖正放，下拖倒回 |
| 四列 | 左缘收入/权益，中左借贷簇，中右资产簇，右缘成本/费用。边缘泡钉在日期线上 |
| 颈 | 两圆靠近时补一条腰，拉开就断。没有贝塞尔连线 |
| 簇 | 固定次数的排斥 + 拉回轴线，相切不重叠。倒放和正放同一进度是同一帧 |
| 大小 | 金额的平方根，膝部之后夹住 |

## 四、数据（不新增会计口径）

```
state.transactions → core/lifevein-model.js → 每日余额 + 事件
state.accounts     →                        泳道 + 是否存量
                        ↓
                  views/lifevein.js（Canvas）
```

- 余额方向沿用 `isDebitType`：**负债「转出」＝欠款增加**。
- 草稿（`status:'draft'`）不参与；缺端照常进事件（绝不自动跳过）。
- 时间轴从最早流水铺到「今天」（今天在账本中间时也要延伸）。
- `core/` 不碰浏览器 API（门禁强制）；渲染全在 `views/`。

## 六、还没做

1. **同一天多笔**：目前按天定位，同一天的几笔会叠在一起，需要按小时内插值；
2. **磁吸与排斥**：同泳道账户多时，泡的间距是均分的，没有真正的避让；
3. **投影片段**：账户之间的转账（两端都是存量）目前不画线；
4. **未来事件**：固定收支 / 分期生成的虚拟流水还没接进来（现在未来是空的）。
