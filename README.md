# Money Way · 资金路径记账

> 看见每一笔钱的来路与去向。

## 子项目

| 子项目 | 说明 | 状态 |
|---|---|---|
| **NT账本**（[`personal/`](personal/)） | 个人记账：流水 / 汇总 / 分类 / 查询 / 分期 / 固定收支 | ✅ 使用中 |
| **经营账** | 经营类计算：成本、库存、应收应付、报表 | 🚧 规划中 |

## 共同点

全部是**零依赖单文件 PWA**：

- **无后端** —— 没有服务器，没有接口，没有数据库
- **单文件** —— 一个 `index.html` 装下全部逻辑和样式
- **离线可用** —— 断网照样开，装在主屏后像原生 App
- **本地加密** —— 数据用 AES-GCM 加密后存在浏览器里，密码不上传
- **数据在你自己手里** —— 换设备靠导出/导入同步文件，不经过任何第三方

## 设计原则

| 原则 | 含义 |
|---|---|
| **流水是唯一事实源** | 所有统计都由流水实时算出，视图层不存数据 |
| **账户是配置** | 类型 / 分类 / 简码 / 期初，只在一处维护 |
| **规则产生未来** | 固定收支、分期、债权形成「计划流水」，到期自动转为事实 |
| **算得出来就不存** | 能由日期推算的（如分期已还期数），绝不落盘 |

详见 [`personal/DATA-MODEL.md`](personal/DATA-MODEL.md)。

## 安全提醒

- 账本数据加密后存在**浏览器本地**（`localStorage`），清浏览器数据会丢，请定期导出备份
- 同一浏览器的不同网址（origin）数据**互不相通**，换地址要先导出再导入
- 忘记密码无法找回 —— 密码是唯一的解密凭据
